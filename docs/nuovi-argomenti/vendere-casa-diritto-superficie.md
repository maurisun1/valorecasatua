# Nuova Situazione: Diritto di superficie

## Dove inserirlo

- **Sezione:** Situazioni (non Mercato)
- **URL:** `/vendere-casa-diritto-superficie/`
- **Cartella:** `vendere-casa-diritto-superficie/`

## Posizionamento consigliato

1. Nav **Situazioni** — voce “Diritto di superficie”
2. Home `#situazioni` — card nella griglia situazioni
3. Footer “Situazioni immobiliari”
4. Link “Leggi anche” da:
   - `/verifica-casa/`
   - `/vendere-casa-non-conforme-difformita/`
   - `/vendere-nuda-proprieta-usufrutto/`
5. Glossario — voce breve “Diritto di superficie” con link alla guida
6. `sitemap.xml`

## Messaggio centrale

La **convenzione** decide la vendita: prezzo massimo di cessione, durata del diritto, requisiti dell’acquirente. I controlli (geometra + notaio / relazione notarile) vanno fatti **prima** di trovare l’acquirente.

## Integrazione via CLI (sul PC)

```bash
cp -R vendere-casa-diritto-superficie /percorso/al/sito-locale/
# poi aggiorna nav, home situazioni, footer, glossary, sitemap
# deploy come di consueto
```
